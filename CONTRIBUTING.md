# Contributing to RenderForge

Thank you for your interest in contributing to RenderForge!

RenderForge is an open-source 3D model generation project. Contributions, bug reports, feature suggestions, and documentation improvements are welcome.

## Getting Started

1. Fork the RenderForge repository.
2. Clone your fork:

   ```bash
   git clone https://github.com/YOUR-USERNAME/renderforgebackend.git
   ```

3. Create a new branch:

   ```bash
   git checkout -b feat/your-feature-name
   ```

4. Install the project dependencies by following the README instructions.
5. Make your changes and test them locally.

## Areas Where You Can Contribute

- AI-powered 3D model generation
- TripoSR and other inference engines
- GPU and memory optimization
- Blender integration
- Mesh processing and optimization
- FastAPI backend development
- Frontend and 3D model visualization
- Bug fixes and documentation
- Testing and performance improvements

## Branch Naming

Use descriptive branch names:

- `feat/feature-name` — New features
- `fix/bug-name` — Bug fixes
- `docs/documentation-name` — Documentation changes
- `refactor/component-name` — Code improvements

## Pull Request Guidelines

Before submitting a pull request:

1. Explain what you changed.
2. Describe the problem your changes solve.
3. Include testing details.
4. Add screenshots or demonstrations when useful.
5. Keep each pull request focused on one improvement.

## Code Guidelines

- Write readable and maintainable code.
- Follow the existing project structure and coding conventions.
- Add tests for new functionality where practical.
- Update documentation when necessary.
- Do not introduce unnecessary dependencies.

## Security

Never commit:

- `.env` files
- API keys or passwords
- Database credentials
- Private user data
- Large model weights without checking their licensing and repository storage requirements

Report security vulnerabilities privately to the repository maintainer rather than posting sensitive details in a public issue.

## Need Help?

Open a GitHub Issue for bugs, questions, or feature suggestions.

Thank you for contributing to RenderForge!
